Formularios en HTML

Texto

Campos de texto basicos: simple, con placeholder, obligatorio (required), de solo lectura (readonly) y deshabilitado (disabled)






contacto

Campos especializados para datos de contacto: contraseña, correo electronico, telefono y URL, cada uno con su propio teclado y validacion en el navegador.




Numericos

Campos para valores Numericos: un numero con limites (min/max) y un deslizador (range) para elegir un valor dentro de un rango.



Fecha y hora

selectores nativos de fecha y hora combinadas,hora,semana del año y mes.






seleccion

controles de seleccion: elegir un color, marca una casilla, elegir una opcion de un grupo de radios y subir un archivo.





lista desplegables (select)

Lista desplegables con el elemento select: una opcion simple, una con valor preseleccionado (selected), una agrupada con optgroup, una de seleccion multiple (multiple) y una deshabilitada (disabled).
